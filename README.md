# Платформа Государственных Стандартов РУз

Веб-платформа для доступа к государственным стандартам Республики Узбекистан с профессиональным переводом на русский язык.

## 📋 Описание проекта

Это веб-приложение предоставляет клиентам доступ к полной базе государственных строительных стандартов Узбекистана, переведенных на русский язык. Пользователи могут бесплатно просматривать первые 2 страницы любого документа, а после оплаты получают полный доступ к документу.

### Основные функции

- 🏠 **Главная страница** - презентация сервиса и его преимуществ
- 📚 **Каталог документов** - поиск и фильтрация по категориям
- 👁️ **Предпросмотр** - бесплатный просмотр первых 2 страниц каждого документа
- 💳 **Оплата** - интеграция с Click, PayMe и банковскими картами
- 🔐 **Авторизация** - регистрация и вход пользователей

## 🛠 Технологический стек

### Frontend
- **React 18** - библиотека для создания пользовательских интерфейсов
- **Vite** - инструмент сборки для быстрой разработки
- **React Router v6** - маршрутизация в приложении
- **CSS3** - стилизация с использованием CSS-переменных

### Backend (в разработке)
Будет развернут на сервере QNAP

## 🚀 Быстрый старт

### Предварительные требования

Убедитесь, что у вас установлены:
- Node.js (версия 18 или выше)
- npm (обычно идет в комплекте с Node.js)

### Установка и запуск

1. **Клонируйте репозиторий**
```bash
git clone <url-репозитория>
cd building-standard-website
```

2. **Перейдите в папку frontend**
```bash
cd frontend
```

3. **Установите зависимости**
```bash
npm install
```

4. **Запустите проект в режиме разработки**
```bash
npm run dev
```

5. **Откройте браузер**

После запуска сервера откройте браузер и перейдите по адресу, который отображается в консоли (обычно `http://localhost:5173`)

### Доступные команды

```bash
# Запуск в режиме разработки
npm run dev

# Сборка проекта для продакшена
npm run build

# Предпросмотр production сборки
npm run preview

# Проверка кода линтером
npm run lint
```

## 📄 Страницы и функциональность

### 1. Главная страница (`/`)
- Приветственный баннер с описанием сервиса
- Блок преимуществ (features)
- Призыв к действию (CTA) для регистрации

### 2. Список документов (`/documents`)
- Поиск по названию документа
- Фильтрация по категориям
- Карточки документов с основной информацией
- Переход к предпросмотру документа

### 3. Предпросмотр документа (`/documents/:id`)
- Отображение информации о документе
- Бесплатный просмотр первых 2 страниц
- Блокировка остальных страниц
- Форма оплаты с выбором способа оплаты

### 4. Вход (`/login`)
- Форма входа с email и паролем
- Ссылка на регистрацию

### 5. Регистрация (`/signup`)
- Форма регистрации с валидацией
- Ссылка на страницу входа
